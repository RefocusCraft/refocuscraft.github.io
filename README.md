# RefocusCraft project page

Public academic project page for **RefocusCraft: Unified Video Refocusing via CoC-Guided State Transitions**.

The top video is the provided `RefocusCraft.mp4`. Interactive demonstrations, figures, and scripts are derived from the author's supplied supplementary page. No citation or BibTeX section is included.

## Preview

Serve this directory with any static HTTP server, then open `index.html`. No build or package installation is required.

## GitHub Pages

The requested root address is `https://refocuscraft.github.io/`. It requires a GitHub account or organization named `refocuscraft`, owning a public repository named `refocuscraft.github.io`.

Publish from the repository's `main` branch and root folder. `.nojekyll` keeps this a plain static site. All required media is local to the repository; the page needs no model server, sign-in, third-party video host, or API key.

Source documents, review PDFs, personal files, credentials, and dataset archives are excluded.
